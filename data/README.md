# Data

`public_inputs.csv` lists every public number in the model with its value, unit, document and page. It is saved from the workbook's public_inputs sheet, which links to section A of the Inputs sheet, so the two always match.

Both source documents are public records on SEC EDGAR:

- AMC Entertainment Holdings, Form 10-K for fiscal 2025, filed 2026-02-23: https://www.sec.gov/Archives/edgar/data/1411579/000141157926000016/amc-20251231x10k.htm
- IMAX Corporation, Form 10-K for fiscal 2025, filed 2026-02-25: https://www.sec.gov/Archives/edgar/data/921582/000162828026011770/imax-20251231.htm

Page numbers are the printed numbers at the bottom of each page of the filing.
